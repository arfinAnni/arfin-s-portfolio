# Arfin’s Portfolio

## 🎯 Project Overview  
This project is my personal portfolio website, built to showcase my work, skill-set, and contact information.  
It’s a clean, responsive front-end site designed to present my projects and background in an effective way.

## 🛠 Built With  
- HTML5  
- CSS3  
- JavaScript (vanilla)  
- Responsive design (mobile & desktop compatible)  
- File Structure:  
  - `index.html` — main landing page  
  - `style.css` — styles for layout, colors, typography  
  - `script.js` — interactive logic (if any)
